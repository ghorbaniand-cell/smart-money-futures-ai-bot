GFTSH Hyperliquid Wallet Observer — V3.26.0 (28-wallet roster)

این نسخهٔ اصلاح‌شده از فهرست V3.25 ساخته شده است. ردیف‌های قبلی ۲۷، ۲۹ و ۳۰ حذف شدند؛ ۲۸ آدرس باقی‌مانده حفظ و شماره‌گذاری مجدد شدند.

- تعداد نهایی: ۲۸ آدرس یکتا و معتبر
- ۲۶ ولت ستاره‌دار پشت سر هم در ابتدای فهرست قرار دارند.
- دو ولت بدون ستاره در انتهای فهرست هستند.
- هیچ آدرس باقی‌مانده‌ای حذف یا تکراری نشده است؛ فقط ردیف‌های درخواستی حذف و شماره‌ها مرتب شدند.
- نام فایل ورکر `gftsh_10_wallet_observer.mjs` و نام ورک‌فلو `GFTSH 10 Wallet Observer` بدون تغییر است.
- زمان‌بندی ورک‌فلو هر ۵ دقیقه تنظیم شده است (اجرای زمان‌بندی‌شدهٔ GitHub best-effort است).
- این ابزار فقط رصد می‌کند: بدون ثبت سفارش و بدون کپی خودکار معامله.

نکته: آمار عملکرد ولت‌ها از طریق این تغییر دوباره راستی‌آزمایی زنده نشده است. فایل باید در مخزن GitHub جایگزین و سپس اجرای آن بررسی شود.

برای استفاده از فهرست داخلی، متغیر `GFTSH_WATCH_WALLETS` را خالی/تنظیم‌نشده بگذار. در صورت استفاده از override، باید دقیقاً ۲۸ آدرس یکتای معتبر وارد شود.
